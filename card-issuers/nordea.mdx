## Endpoints

| Method | Path | Auth |
|--------|------|------|
| `POST` | `/api/v1/issuers/nordea/cards/{cardId}/transaction_states` | OAuth (`issuer-nordea-transaction-states-write`) |
| `POST` | `/api/v1/issuer/nordea/partner-event` | mTLS |

---

## Transaction states

Same payload as [Transaction States](/card-issuers/transaction-states). Nordea allows nullable: `merchant_number`, `terminal_id`, `rrn`, `auth_code`.

---

## Partner events (batch)

```
POST /api/v1/issuer/nordea/partner-event
```

Authenticated via mutual TLS:
- `X-SSL-Client-CN`
- `X-SSL-Client-Fingerprint`

Batch payload with encrypted transaction data. Returns `201` on success, `400` with `{errorCode: "TX_DATA_ERROR"}` on bad data.

---

## TPA activation

When Nordea confirms cards for a buyer/seller party → `TpaService::setActivated()` → TPA goes live.

Nordea receives signed TPA PDF via email when signing completes.
