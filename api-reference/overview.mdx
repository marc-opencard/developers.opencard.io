## APIs

| API | Base URL | For |
|-----|----------|-----|
| **OAuth** | `/oauth/token` | Get access tokens |
| **Application** | `/api/v1/application` | EMS integration |
| **Issuer** | `/api/v1/issuers/{issuer}` | Card issuers |
| **Receipt Callback** | `/api/v1/service/marcet/callback/{id}` | Receipt providers (inbound) |

## OpenAPI specs

All specs are **generated from `service.opencard.api` source code**, not copied from legacy swagger.

```bash
# Regenerate specs after API changes
npm run sync-openapi
# or
python3 scripts/generate-openapi.py
```

Specs live in `/openapi/`:
- `oauth.json`
- `application-api.json`
- `issuer-api.json`
- `receipt-provider-callback.json`

## Auth

Every Application + Issuer endpoint requires:

```
Authorization: Bearer {access_token}
```

Get token via `POST /oauth/token` with `grant_type=client_credentials`.

## Conventions

- JSON request/response bodies
- Pagination via `page` + `per_page` query params
- Path params: `{accountId}`, `{organizationId}`, `{tpaId}`, etc.
- Errors: `401` (auth), `403` (scope), `404` (not found), `422` (validation)

## Web signing endpoints (not in OpenAPI)

These are browser flows, not API calls:

| Flow | URL |
|------|-----|
| TPA signing | `GET/POST /accounts/{accountId}/tpas/{tpaId}/sign/{token}` |
| PDPC signing | `GET/POST /accounts/{accountId}/pdpcs/{pdpcId}/sign/{token}` |

Documented in [TPA Flow](/ems/tpa-flow) and [PDPC Flow](/ems/pdpc-flow).
