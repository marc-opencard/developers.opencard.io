---
title: Transaction state
description: Transaction state entity in the OpenCard EMS data model — point-in-time snapshot across the authorized, cleared, deleted, and invoiced webhook events.
---

Point-in-time snapshot of a transaction. Each state change fires a separate `card.transaction.*` webhook.

| State | Meaning |
|-------|---------|
| `authorized` | Purchase just happened — preview only |
| `cleared` | Settled — use for accounting |
| `deleted` | Auth reversed |
| `invoiced` | Has invoice number from issuer |
